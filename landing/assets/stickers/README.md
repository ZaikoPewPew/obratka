# Stickers (landing)

Ассеты для peel-стикера на intro: [`../src/stickerPeel.js`](../src/stickerPeel.js).

Сейчас на экране: **`hero.png`** (или `hero.svg` как временный плейсхолдер).  
Новые файлы клади сюда → скажи имя → подключим в `landing/src/main.js`.

## Формат выноса (предпочтительно)

| | |
|---|---|
| **Формат** | **PNG** с альфой (прозрачный фон) |
| **Цвет** | sRGB |
| **Размер** | **512×512** (или 400–640 по длинной стороне) |
| **Соотношение** | квадрат или близко к квадрату |
| **Имя** | `kebab-case.png` — `hero.png`, `duck.png`, `grade-junior.png` |

### Как должен выглядеть файл

1. **Прозрачный фон** — не JPG, не белый квадрат под объектом.
2. **Белая / светлая обводка «наклейки»** (die-cut) 8–16 px на 512 — peel и оборот выглядят убедительно.
3. **Без запечённой тени** — тень даёт компонент (`--landing-sticker-shadow-opacity`).
4. **Объект по центру**, с запасом до края: ~10–15% padding, чтобы flap при отклеивании не обрезался странно.
5. **Один стикер = один файл.** Не атласы / не спрайты.

### Ок как запасной вариант

- **SVG** — если уже вектор и простая заливка (как текущий `hero.svg`).
- **WebP** с альфой — тоже ок, если удобнее весить меньше.

### Не подходит

- JPEG / PNG без альфы с серым/белым фоном
- Слишком мелкий исходник (&lt; 256 px) — на ретине мылит
- Гигантские 4K без нужды — бандл раздувается

## Figma / экспорт

1. Фрейм **512×512**, фон пустой.
2. Арт + обводка стикера.
3. Export → **PNG**, `1x` (или `2x` если рисуешь в 256 и хочешь 512).
4. Имя файла латиницей, без пробелов.

## Подключение

В [`landing/src/main.js`](../src/main.js):

```js
import stickerSrc from "../assets/stickers/hero.png";
```

Позиция / размер на экране — токены `--landing-sticker-*` в `styles/tokens.css`, не в самом PNG.
